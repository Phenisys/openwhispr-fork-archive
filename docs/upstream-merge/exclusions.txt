# Manifeste d'exclusion Phenisys — appliqué à chaque fusion amont.
#
# Rôle : après un `git merge <tag-upstream>`, ces chemins sont supprimés
# automatiquement (scripts/upstream_merge_resolve.py), puis une assertion
# vérifie qu'aucun ne subsiste. C'est la forme MÉCANIQUE de la divergence du
# fork : la politique BYOK / local / self-hosted (pas de couche
# compte/login/cloud/workspace/billing/sync/MS-Calendar/enterprise).
#
# [purged]    Liste AUTORITAIRE des chemins que le fork a supprimés et
#             maintient supprimés. Régénérable :
#               git diff --name-status 1866ecf6..origin/main | awk '$1=="D"{print $2}'
# [excluded]  Fichiers de la couche exclue arrivés avec l'amont (donc sans
#             conflit : ils s'ajouteraient silencieusement). Liste vérifiée
#             fichier par fichier pour la fenêtre de fusion courante.
# [warn]      Motifs d'ALERTE, non destructifs. Le script signale tout fichier
#             correspondant qui n'est ni dans [purged] ni dans [excluded] :
#             un nouveau fichier de la couche exclue apparu dans une version
#             suivante est ainsi repéré, mais rien n'est supprimé sans relecture.
#             Ces motifs ont été validés sans faux positif sur l'arbre v1.10.0.
#
# Ajouter un chemin ici = décider d'exclure de la couche officielle. À traiter
# comme du code : relu, versionné, et cité dans le PV de la fusion.
#
# ⚠️ AVANT D'EXCLURE UN FICHIER, VÉRIFIER CE QU'IL PORTE. Un fichier de la
# couche cloud contient souvent des fonctionnalités qui n'ont rien de cloud :
# `src/components/notes/SpacesTree.tsx` portait le menu d'actions des notes
# (supprimer, renommer) ; l'avoir exclu a fait disparaître le bouton de
# suppression de nos notes locales. Dans ce cas : PORTER la fonctionnalité (et
# son test) dans notre équivalent local AVANT d'ajouter le chemin ici, et
# l'inscrire au contrat `parity-checks.txt` pour qu'elle ne reparte pas.
# L'audit `scripts/upstream-parity-audit.mjs` refuse un fichier amont non
# classé, mais il ne peut pas voir ce qui a été perdu À L'INTÉRIEUR d'un
# fichier exclu : cette relecture reste humaine.
